Pad is points the last name in the depth still gets (#1 gets depth+pad). Depth is how many names each model ranks; 0 keeps the vote on the first 5 so a long Top-N list does not scramble the shortlist. Mix is how hard those ballots pull the blend (40 = current). Floor drops models below that weight from the vote (stops 8/25 padding). Cross-section × is the neighbour/bundle prior (5 = current).
